# Employment Anxiety and Career Readiness Analysis

A Tableau-based data analysis project developed as a college project to study employment anxiety and career readiness among students.

The project uses survey response data to analyze students' concerns about employment, preparedness for careers, and related factors through Tableau visualizations and dashboard/reporting.

## Features

- Student survey data analysis
- Tableau dashboard creation
- Career readiness analysis
- Employment anxiety analysis
- Data visualization using charts and dashboards
- Project report included
- Dataset included for analysis

## Technologies Used

- Tableau
- Microsoft Excel
- Data Analysis
- Data Visualization

## Purpose
This project was created to understand how students feel about employment opportunities and how ready they are for their careers.
It helped me practice data collection, data cleaning, dashboard creation, and analysis using Tableau.
